Флаг	Что делает
-u	URL с точкой подстановки FUZZ
-w	Словарь
-e	Расширения файлов
-H	HTTP-заголовок
-X	HTTP-метод
-d	Тело запроса
-b	Cookie
-mc	Какие HTTP-коды показывать
-fc	Какие HTTP-коды исключать
-fs	Исключить ответы указанного размера
-fw	Исключить ответы с указанным числом слов
-fl	Исключить ответы с указанным числом строк
-fr	Исключить ответы по регулярному выражению
-ac	Автоматическая калибровка ответов
-recursion	Рекурсивный поиск
-recursion-depth	Глубина рекурсии
-t	Число параллельных потоков
-rate	Ограничение запросов в секунду
-maxtime	Максимальное время выполнения
-o	Файл результатов
-of	Формат файла результатов
-v	Подробный вывод
